# Get Shit Done

A modern Todo application built with React and Tailwind CSS.

## 🚀 Live Demo

https://get-shit-done-psi.vercel.app/

## Features

- Add todos
- Edit todos
- Delete todos
- Mark completed
- Local Storage persistence
- Responsive UI

## Tech Stack

- React
- JavaScript
- Tailwind CSS
- Vite
- UUID
